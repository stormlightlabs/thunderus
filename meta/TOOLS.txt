read
  Read the contents of a file. Supports text files and images (jpg, png,
  gif, webp). Images are returned as base64 payloads. For text files,
  defaults to first 2000 lines. Use offset/limit for large files.
  - path: Path to the file to read (relative or absolute)
  - offset: Line number to start reading from (1-indexed)
  - limit: Maximum number of lines to read

write
  Write content to a file. Create or overwrite files.
  - path: Path to the file to write
  - content: Full file contents to write

edit
  Apply surgical edits to an existing file.
  - path: Path to the file to edit
  - diff: A unified diff patch to apply

bash
  Execute bash commands in the repo sandbox.
  - command: The shell command to run

research
  Fetch and read a specific public HTTPS URL.
  Use for: API docs, library behavior, standards, CLI flags, recent changes.
  Do NOT use for: secrets, credentials, proprietary/private content.
  - url: The URL to fetch

memory_store
  Save durable memory for future conversations.
  Use for: facts, preferences, procedures, or persistent context.
  - content: The memory content to store
  - kind: One of fact, preference, procedure, context
  - tags: Optional list of tag strings

memory_recall
  Search previously stored memory.
  Use for: recalling preferences, prior decisions, known facts, or procedures.
  - query: Search query for relevant memory
  - kind: Optional filter (fact, preference, procedure, context)
  - count: Optional result count (1-20)
