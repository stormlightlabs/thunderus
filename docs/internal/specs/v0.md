# v0 and Alpha Spec

## Remaining Internal Scope

The following work is still planning/spec material and should stay internal:

- Config file support.
- Non-TUI inspect and export commands.
- v1 compatibility guarantees.

## Internal Release Notes

Alpha can keep changing CLI, config, and session contracts. v1 should define the
supported public surface for CLI flags, config keys, environment variables,
session/event formats, tool behavior, and documented workflows.
