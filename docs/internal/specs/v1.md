# v1 Spec

v1 defines the supported user-facing contract for `thndrs`: stable CLI/config
behavior, durable session inspection, documented AGENTS.md semantics, recoverable
file operations, packaging, release notes, and a release candidate checklist.

## Release Goal

Goal: define the supported user-facing contract and make the harness safe enough
to install and use repeatedly.

Required:

- Stable CLI flags, environment variables, config file keys, and session format.
- Documented AGENTS.md precedence, scoping, size caps, and session audit behavior.
- `--help` documents default model, search modes, config path, and session path.
- Config file support with CLI/env overrides and clear precedence.
- File write/edit behavior is documented, bounded, and recoverable.
- Session inspect/export can read sessions without opening the TUI.
- Release notes follow a changelog format.
- Packaging supports at least `cargo install`.
- CI runs formatting, clippy, unit tests, snapshot tests, and no-network provider
  fixture tests.
- Upgrade behavior is documented for alpha session/config changes.

## Public Contract

For this CLI app, v1 public contract includes:

- CLI flags and subcommands.
- Environment variables.
- Config file path and keys.
- Session JSONL schema.
- Tool names, inputs, and safety limits.
- AGENTS.md precedence and scoping.
- Exit codes for non-TUI commands.
- Documented install and upgrade workflow.

## CLI And Config

v1 may add non-TUI `inspect` and `export` commands once sessions exist.

Config precedence:

1. CLI flags.
2. Environment variables.
3. Config file.
4. Built-in defaults.

Config should cover:

- Default model.
- Web search mode.
- Session path.
- Tick rate.
- Default workspace behavior.

Secrets stay out of config examples. `UMANS_API_KEY` remains the secret path.

## Session Inspect And Export

Non-TUI commands should output JSON or JSONL and include:

- Transcript entries.
- Provider/model metadata.
- Tool events.
- Loaded AGENTS.md paths, scopes, hashes, and truncation state.
- File-operation audit metadata.

Inspect/export must not leak API keys or machine-specific transient data.

## AGENTS.md Contract

Document:

- Precedence: harness policy, user prompt, CLI/config, nearest AGENTS.md,
  broader AGENTS.md, defaults.
- Root and nested file scoping.
- Size caps and truncation behavior.
- Session audit metadata.
- Authoring guidance and common smells: context bloat, lint leakage,
  tool-specific skill leakage, and conflicting instructions.

Repository instructions cannot grant permissions, change provider/model settings,
bypass tests, disable safety checks, reveal secrets, or override user/system
instructions.

## File Operations Contract

Supported write operations:

- Create file.
- Exact-range replace.
- Unified patch apply.

Required behavior:

- All writes are recorded as structured transcript/tool events.
- Failed edits leave files unchanged.
- File path, operation type, and result are visible.
- User can recover by inspecting session events and normal `git diff`.
- Long-running shell/process execution remains out of scope.

## Release Candidate Bar

- No known data-loss bugs.
- No known terminal cleanup bugs.
- No known secret leakage in logs, snapshots, sessions, or errors.
- All non-network tests pass from a clean checkout.
- Manual Umans smoke test passes with `UMANS_API_KEY`.
- Packaging smoke test passes from a local package artifact.
- v1 known limitations are documented.

## Required Checks
