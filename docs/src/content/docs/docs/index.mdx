`thndrs` is a minimal, LLM powered pair programmer.

It provides a terminal UI for chatting with an LLM and tools to read and modify code
based on context/project guidance you provide. Like [pi](https://pi.dev), it's meant
to stay focused on reading and writing code with the essentials. You provide it with
the command-line tools you need for your projects.

## Features

- Chat with a coding agent in the terminal while keeping normal terminal
  scrollback, search, and text selection.
- `AGENTS.md` support
- `SKILL.md` support
- Provider support for ChatGPT Codex, OpenCode Go, and OpenCode Zen Big Pickle.
- MCP-configured web search and built-in public URL reading
- Agent Client Protocol support lets you use external ACP agents from the TUI,
  or run `thndrs acp serve` so editors and IDEs can drive the `thndrs` harness
  over stdio.
  - See [ACP](/docs/usage/acp/) for agent configuration, editor setup, supported
    capabilities, permission behavior, and troubleshooting.
- Session history
- Visible context control with pin, drop, recover, and review actions
- Model-specific reasoning controls
