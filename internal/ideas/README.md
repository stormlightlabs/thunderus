# Ideas

Output of `/r-d` sessions. One file per idea.

An idea records decisions and the reasoning that would be expensive to
reconstruct. It is not a specification and not a task.

An idea becomes work when it has acceptance criteria someone could verify. File
it as an issue then, or as an epic with sub-issues, and link back here.

Every file carries `name`, `last_updated`, and a ULID `id`. Generate the
identifier with `.claude/scripts/ulid.py`.
